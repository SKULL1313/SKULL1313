### What I am working on

**NLAH-Builder** &nbsp;·&nbsp; NLP research, UMD DATA/MSML 641 &nbsp;·&nbsp; [repo](https://github.com/SKULL1313/UMD-DATA641-MSML641)

Turns plain-English project descriptions into structured rules for coding agents. I led data and evaluation.

- Hand-labeled 30 real documents into **763 gold values** against an 8-slot schema, wrote the annotation
  guidelines, and measured annotator agreement
- Replaced a keyword-rule extractor with a trained classifier, raising micro F1 from **0.05 to 0.20** under
  leave-one-document-out cross-validation
- Measured the ceiling rather than claiming the win: a blind second human pass scores 0.30, putting the
  model at **55% of human performance**, so the labels are the limit, not the method
- Built a 20-trial blind harness measuring whether the generated rules change what an agent does. Forbidden
  file reads went from **3/3 to 0/3**. Task success did not move, and I reported that too.
